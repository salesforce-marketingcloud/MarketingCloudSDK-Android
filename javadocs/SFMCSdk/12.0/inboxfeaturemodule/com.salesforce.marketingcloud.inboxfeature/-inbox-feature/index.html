InboxFeature

class InboxFeature : ModuleInterface

Public entry point for the Inbox feature within the Salesforce Marketing Cloud SDK. Implements ModuleInterface so the unified SDK can report state and dispatch scheduled jobs to Inbox.

Owns Inbox storage, the public InboxMessageManager, the runtime enable/disable toggle and GDPR handling. Mirrors the shape of the other feature modules, InAppMessagingFeature and MobileAppMessaging.

fun enableInbox()

Enables Inbox at runtime and persists the choice across restarts. Refused (logged, no state change) while GDPR-blocked. When Inbox goes from disabled to enabled, fetching resumes.
